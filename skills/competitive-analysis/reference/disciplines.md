# Five Disciplines · 五大纪律完整版

> SKILL.md 表格的展开版。违反任一即视为任务失败。

## 1. 流程纪律

- **第一步必须是澄清**（`AskUserQuestion`），不要跳过
- 拿到澄清答案后才能 WebSearch
- 找到 N 个竞品后**立即开始调研**，不要继续探索性搜索
- 综合阶段不再扩展新竞品

## 2. 预算纪律

- 总工具调用上限：**30 次**
- 时间过半时**必须开始综合**，不要陷入完美主义
- 单竞品工具上限：WebSearch ≤ 3、WebFetch ≤ 5

## 3. 引用纪律 ⭐

**分两类对待**：

### 事实信息 → 必须有真实访问过的 URL
适用于：
- 产品定位 / 一句话定位
- 核心功能列表
- 价格 / 套餐 / 限额
- 融资金额 / 轮次 / 时间
- 客户案例 / Logo
- 用户评价（好评 / 差评）
- 团队规模 / 总部 / 成立时间

### 分析结论 → 不需逐句引用
适用于：
- SWOT 各象限的判断
- 差异化分析
- 战略建议
- 定位象限的横纵轴划分

**但**：必须**基于前文已引用的事实**推导，不可凭空判断。

### 通用约束

- ❌ 禁止凭空构造 URL / 编造引用
- ❌ 禁止用 "many users believe..." 类模糊词替代具体引用
- ✅ 来源无法确认时写 "信息不足，建议进一步调研"，不要猜测
- ✅ 报告中事实陈述标注 inline URL（如 `[github.com/features/copilot]`）

## 4. 错误纪律

- `WebFetch` 失败 → **换 URL** 而非重试同一个
- `WebSearch` 结果差 → **换 query 关键词**（最多换 1 次）
- 同竞品同字段连续 2 次抓不到 → **标 `null` 跳过**，进入 `gaps`
- 整个竞品调研失败 → 在报告中显式声明 "X 信息不足"，不要伪造

## 5. 收敛纪律

### 综合阶段补搜规则

- ✅ 允许：为**已选竞品**补抓关键缺失字段（pricing / official features / negative reviews）
- ❌ 禁止：扩展新竞品
- ❌ 禁止：做探索性 WebSearch
- ⚠️ 上限：补搜总次数 **≤ 3**

### 触发"立即停止调研、开始写报告"的条件（任一满足即停）

1. N 个竞品全部完成（部分字段缺失也算完成）
2. 总工具调用 ≥ 30 次
3. 已用时间 ≥ 总预算的 70%

### 禁止行为

- ❌ "再多搜一点会更好" — 不！立刻写报告
- ❌ "这个字段还不够完美" — 标 `null` 进 gaps，继续
- ❌ "用户可能想看更多竞品" — 综合阶段不扩
