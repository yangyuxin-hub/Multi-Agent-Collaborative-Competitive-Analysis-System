# 竞品分析领域知识（写报告必读）

> 决定 `extract_fields` tool 抽什么字段、主 agent 综合什么矩阵、写什么洞察的**业务侧依据**。

---

## 一、不同读者关心的东西完全不同

主 agent 必须用 `ask_user` 先问"**你是哪种视角看这份报告？**"——视角决定字段权重。

| 读者 | 用途 | 最关心 |
|------|-----|--------|
| **产品经理** | 决定下个季度做什么功能、怎么差异化 | 功能矩阵、用户痛点、迭代速度 |
| **创业者 / 战略** | 决定要不要进这个赛道、定位往哪打 | 市场格局、融资情况、护城河 |
| **投资人 / BD** | 决定要不要投、估值多少 | 商业模式、收入、增长曲线、团队 |
| **销售 / Marketing** | 销售对话怎么应对、Battlecard | 定价、目标客户、客户吐槽点 |
| **求职者 / 行业研究** | 判断行业趋势 | 全景图、领头羊、新兴玩家 |

## 二、信息金字塔（按重要性五层）

### 第 1 层 — 身份（必有，最基础）
- 产品名 + 公司名 + 官网
- 一句话定位
- 成立时间 / 团队规模 / 总部 / 公司类型
- **来源**：官网首页 + Crunchbase + Wikipedia

### 第 2 层 — 产品（核心 ⭐⭐⭐）
- 核心功能列表（3-5 个杀手锏）
- **功能矩阵**（横向对比谁有谁没） ← 矩阵 1
- 技术亮点 / 平台支持 / 集成生态 / 数据隐私合规

### 第 3 层 — 商业（决策核心 ⭐⭐⭐）
- **定价矩阵**（免费版 / Pro / 企业版） ← 矩阵 2
- 商业模式（订阅 / 按量 / 一次性 / Freemium）
- 目标客户 / 收入估算 / 用户规模 / 融资情况

### 第 4 层 — 口碑（差异化关键 ⭐⭐）
- 用户评价（**好评 + 差评**）
- 典型客户 logo / 增长信号 / 社区活跃度 / 渠道策略

> 差评里藏着机会，**必须抓**。

### 第 5 层 — 战略洞察（报告灵魂 ⭐⭐⭐）
分析框架（不是字段）：
- **SWOT**（优势/劣势/机会/威胁）
- **市场定位图**（横轴价格 / 纵轴功能复杂度）
- 差异化分析 / 护城河评估 / 趋势判断 / 给"自己产品"的建议

## 五、Researcher subagent 返回卡片 Schema（`extract_fields` 目标）

```python
class Competitor(TypedDict):
    # 第 1 层 身份
    name: str
    company: str
    website: str
    one_liner: str
    founded: str | None
    headquarters: str | None
    team_size: str | None

    # 第 2 层 产品
    core_features: list[str]
    feature_flags: dict[str, Literal["full", "partial", "none"]]
    platforms: list[str]
    integrations: list[str]
    tech_stack: list[str] | None

    # 第 3 层 商业
    pricing_tiers: list[dict]    # [{name: "Pro", price: "$10/mo", limits: "..."}]
    business_model: str
    target_audience: list[str]
    funding: dict | None
    notable_customers: list[str] | None

    # 第 4 层 口碑
    positive_reviews: list[str]
    negative_reviews: list[str]
    growth_signals: list[str]

    source_ids: list[str]    # 引用 sources_pool 中的 id
```

| 定价 | P0 | 官网 /pricing |
| 融资 | P0 | Crunchbase / 36氪 / TechCrunch |

**搜索关键词模板**：

```
"{product} pricing"
"{product} features review"
"{product} vs {competitor}"            ← 最强，直接拿对比文章
"{product} funding crunchbase"
"{product} reddit users complain"      ← 挖差评
"alternatives to {product}"             ← 反向找竞品
```

## 七、新手常踩的坑

| ❌ 做错 | ✅ 应该 |
|--------|--------|
| 堆字段不分轻重，50 个字段塞满 | 3-5 个核心维度 + 1 张大表，聚焦才有密度 |
| 只汇总不分析（"A 支持 X，B 也支持 X"）| 对比 + 判断（"只有 A 能跨库语义搜索——这是护城河"）|
| 只列优点 | **必含差评和痛点**，差评是机会 |
| 信息时间静止 | 带时间戳 + 趋势线 |

## 九、竞品分析的用户与目的

竞品分析不是为了"看看别人做了什么"，而是为了帮助不同角色做决策。主 agent 在开局必须识别报告读者，否则报告很容易变成功能清单。

| 用户 | 核心目的 | 典型输出 |
|------|----------|----------|
| 创始人 / CEO | 判断市场机会、差异化空间、商业模式是否成立 | 市场格局、战略机会、进入建议 |
| 产品经理 | 辅助产品定位、功能优先级、路线图决策 | 功能矩阵、痛点洞察、路线图建议 |
| 产品营销 / 市场团队 | 制定定位、卖点、内容策略和获客打法 | 定位对比、卖点拆解、内容/渠道建议 |
| 销售团队 | 在客户比较竞品时赢单 | Battle card、异议处理、赢单话术 |
| 投资人 / 战略团队 | 判断护城河、市场格局、增长风险 | 行业格局、壁垒评估、风险判断 |
| 运营 / 增长团队 | 找到获客、转化、留存上的可借鉴打法 | SEO/渠道分析、转化路径、增长实验建议 |

主要目的：

- **确认市场格局**：识别直接竞品、间接竞品、替代方案、潜在竞品。
- **找到差异化定位**：明确在人群、价格、功能、体验、渠道、服务、品牌等维度上如何不同。
- **发现用户真实需求**：从评论、社区、投诉、迁移故事中识别满意点和不满点。
- **指导产品决策**：区分行业标配、差异化机会和竞品噪音。
- **支持商业化和定价**：理解套餐、计费单位、免费版策略和用户付费边界。
- **提升销售胜率**：形成"什么时候我们赢、什么时候竞品赢、如何回应异议"的材料。
- **识别风险和机会**：通过融资、招聘、更新、内容布局、客户评价推测竞品下一步。

## 十、竞品类型

报告里不应该只列"最像我们的产品"。不同类型的竞品代表不同风险。

| 类型 | 定义 | 例子 / 判断方式 |
|------|------|----------------|
| 直接竞品 | 解决同一问题，服务同一类用户，产品形态相近 | Notion vs Coda，飞书文档 vs 腾讯文档 |
| 间接竞品 | 解决同一用户目标，但产品形态不同 | 项目管理工具的间接竞品可能是 Excel、飞书表格、微信群 |
| 替代方案 | 用户不用你的产品，也能完成任务 | CRM 的替代方案可能是销售自己维护 Excel |
| 潜在竞品 | 现在还不是竞品，但有能力进入市场 | 大厂平台、相邻品类工具、已有用户/数据优势的公司 |
| 标杆竞品 | 不直接竞争，但在体验、商业模式、增长、品牌上值得学习 | AI 工具参考 Perplexity 的搜索体验，参考 Notion 的模板生态 |
| 上下游 / 相邻竞品 | 位于同一用户流程前后环节，未来可能向你的环节扩展 | 会议纪要工具的相邻竞品包括视频会议、日历、任务管理工具 |
| 内容 / 流量竞品 | 不一定卖同类产品，但争夺同一批用户注意力或关键词 | SaaS 官网与行业媒体、评测站、竞品博客争夺 SEO 流量 |
| 预算竞品 | 产品形态不同，但争夺同一笔预算 | CRM、营销自动化、销售外呼系统可能互相竞争预算 |

最常用的四层：**直接竞品、间接竞品、替代方案、潜在竞品**。其他类型按分析目的补充。

## 十一、分析维度与数据来源补充

### 核心分析维度

| 维度 | 看什么 | 目的 |
|------|--------|------|
| 公司与市场背景 | 成立时间、融资、团队、目标市场、主要客户 | 判断资源、阶段、战略野心和市场位置 |
| 目标用户 | 个人、团队、企业、大客户、开发者、运营、销售等 | 判断是否争夺同一批用户 |
| 产品定位 | 官网如何描述自己，主打场景、价值和差异化 | 理解它想占据的用户心智 |
| 核心功能 | 主要功能、特色功能、工作流、集成、AI、权限、协作、自动化 | 区分行业标配和差异化机会 |
| 用户体验 | 注册、onboarding、核心路径、信息架构、交互、性能、移动端 | 发现体验优势、转化阻力和可借鉴设计 |
| 定价与商业模式 | 免费版、套餐、计费单位、试用、企业版、增值服务 | 判断价格锚点和商业化策略 |
| 获客与增长 | SEO、广告、内容、社群、渠道、模板生态、裂变、联盟计划 | 理解它怎么拿用户 |
| 客户与案例 | 客户类型、行业分布、Logo wall、案例文章、testimonial | 判断落地行业和验证场景 |
| 用户评价与口碑 | 好评、差评、投诉、迁移原因、社区讨论 | 发现真实痛点 |
| 技术与生态 | API、插件、集成、安全合规、部署方式 | 判断扩展性、企业适配能力和技术壁垒 |
| 销售打法 | PLG、自助购买、销售驱动、渠道销售、大客户定制 | 判断它如何赢单 |
| 战略信号 | 招聘、融资、产品更新、并购、路线图、公开访谈 | 推测下一步投入方向 |

### 常用数据来源

| 数据来源 | 典型位置 | 价值 |
|----------|----------|------|
| 官网 | 首页、功能页、价格页、行业方案、客户案例 | 官方定位、功能包装、目标客户、定价 |
| 产品本身 | 试用、Demo、帮助中心、模板库、API 文档 | 验证真实功能和使用体验 |
| 应用商店 / 插件市场 | App Store、Google Play、Chrome Web Store、Slack/Notion/Shopify marketplace | 评分、评论、下载量、集成生态 |
| 评价网站 | G2、Capterra、Trustpilot、Product Hunt、AlternativeTo | 用户满意点、不满点、替代关系 |
| 社交媒体与社区 | X/Twitter、Reddit、知乎、小红书、即刻、Discord、论坛 | 真实讨论、抱怨、推荐、迁移原因 |
| SEO 与内容数据 | Google/百度、Ahrefs、Semrush、Similarweb、站长工具 | 流量来源、关键词、内容策略 |
| 新闻与融资数据库 | Crunchbase、企查查、天眼查、IT 桔子、36氪、TechCrunch | 融资、并购、团队、市场热度 |
| 招聘信息 | LinkedIn、Boss 直聘、拉勾、公司招聘页 | 判断正在投入的方向 |
| 客户案例与招投标 | 官网案例、客户新闻稿、政府采购网、企业招标平台 | 客户类型、客单价、行业落地 |
| 财报与公开文件 | 年报、SEC 文件、投资者电话会 | 上市公司收入、增长、利润和战略重点 |
| 广告与投放 | Meta Ads Library、Google Ads Transparency、巨量创意、百度营销案例 | 当前主推卖点、人群、投放强度 |
| 一线访谈 | 目标用户、流失用户、销售、客服、渠道伙伴 | 解释用户为什么真的选择或放弃 |

## 十二、如何评价竞品分析好坏

好坏的核心标准：**能不能支持决策**，而不是页数多不多、表格全不全。

### 好的竞品分析

- **问题明确**：知道是为了产品路线图、定价、销售 battle card、市场定位，还是投资判断。
- **竞品选择合理**：覆盖直接竞品、间接竞品、替代方案和潜在竞品，每个竞品入选都有理由。
- **数据有来源**：功能、价格、用户评价、融资、客户案例等都有可追溯来源。
- **维度服务目的**：为产品决策看场景、功能、体验；为销售看价格、差异化、客户异议；为市场看定位、内容、渠道。
- **不只罗列功能**：解释为什么这样设计、用户为什么买、这对我们意味着什么。
- **区分事实、判断和建议**：事实可验证，判断有依据，建议能行动。
- **指出机会和风险**：明确该补齐什么、避开什么、差异化在哪里、对方下一步可能做什么。
- **输出可行动**：能落到路线图、话术、定价、定位或增长动作。

### 差的竞品分析

- 没有明确目的，上来就列一堆竞品和功能表。
- 竞品选择随意，只选最有名或最像的，漏掉替代方案和潜在威胁。
- 数据来源不清，大量依赖"感觉"和二手传言。
- 只做功能 checklist，无法回答"所以我们该怎么办"。
- 过度主观，使用"体验好""功能强""用户喜欢"等空泛词。
- 忽略用户场景，只比较产品，不看用户为什么选择或流失。
- 没有时效性，价格、功能、融资、招聘、市场打法不标日期。
- 结论无法落地，只写"加强体验""提升品牌"这类泛泛建议。

### 快速评分问题

| 评价问题 | 好的标准 |
|----------|----------|
| 分析目的清楚吗 | 明确服务哪个角色和哪个决策 |
| 竞品选得对吗 | 覆盖直接竞品、替代方案、关键标杆 |
| 数据可信吗 | 有来源、有日期、能复核 |
| 分析够深入吗 | 解释原因和影响，而不是只列事实 |
| 结论有取舍吗 | 明确优先级，不是什么都建议做 |
| 能推动行动吗 | 能转成路线图、话术、定价、定位或增长动作 |

一句话：**差的竞品分析告诉你"别人有什么"，好的竞品分析告诉你"我们该怎么赢"。**
